# genomics_ancest_disease_dispar

Code for a meta-science study of the GWAS Catalog. 

[Workflowr page](https://ijbeasley.github.io/genomics_ancest_disease_dispar/index.html)

# Software requirements 

- R version 4.3.2 (packages tracked by renv, see renv.lock)
- Python version (3.12.12, venv environment packages see spacy_venv_requirements.txt)

For annotating text: 
- Doccano (install via docker image, see https://doccano.github.io/doccano/)

For processing publisher specific xml formats: 
- Auto-CORPus (https://github.com/omicsNLP/Auto-CORPus) 

For detecting abbreviations in text: 
- Ab3p (https://github.com/ncbi-nlp/Ab3P)
