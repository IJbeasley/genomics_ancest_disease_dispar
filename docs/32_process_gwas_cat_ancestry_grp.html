In the GWAS Catalog, broad ancestry grouping in some cases is listed as ‘NR’ or includes multiple ancestry groups even though the descriptions provided would allow us to infer a more specific ancestry group. This script pre-processes the GWAS Catalog ancestry dataset to harmonize the broad ancestry grouping and extract population descriptors from the sample descriptions.

Account for sibling pairs / trios in numbers

The leading number in a sample description usually counts individuals, including “N individuals from M families”. Only when the description ends with a group unit (e.g. “69 European ancestry trios”) does it count groups. NUMBER_OF_INDIVIDUALS is left unchanged; only n is converted.

initial_sample_desc <-
  initial_sample_desc |>
  mutate(
    n_text = n,  # number as written in the description
    multiplier = case_when(
      str_detect(sample_description, "\\btrios$")          ~ 3,
      str_detect(sample_description, "\\b(duos|pairs)$")   ~ 2,
      TRUE                                                ~ 1
    ),
    n = n_text * multiplier
  )

# Units with no fixed size: use the total reported in the paper.
# GCST005536 (PMID 25751624): 10,796 individuals in 2,601 ASP families + 69 trios,
# so ASP families = 10,796 - 3 * 69 = 10,589 individuals
initial_sample_desc <-
  initial_sample_desc |>
  mutate(
    n_overridden = STUDY_ACCESSION == "GCST005536" &
                   str_detect(sample_description, "affected sibling pair families$"),
    n = if_else(n_overridden, 10589, n)
  )

# Stop if a new catalog release adds a group unit that isn't handled above
unhandled_units <-
  initial_sample_desc |>
  filter(str_detect(sample_description,
                    "\\b(families|sibships|pedigrees|twins|quads)$"),
