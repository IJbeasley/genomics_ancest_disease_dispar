Introduction

Studies are added to the GWAS Catalog at a different time to when they are published. Often this is after the publication date, but sometimes it is before.

This means the number of publications in more recent years is censored (incomplete). To decide how recent a publication can be while still expecting it to be in the Catalog, this analysis measures the gap between each study’s publication date (DATE) and the date it was added to the Catalog (DATE_ADDED_TO_CATALOG). It then checks whether that gap has changed over time.

Calculate the publication-to-catalog gap

# Number of months between two dates (fractional months)
months_gap <- function(start_date, end_date) {

  # Convert input dates to Date class
  start_date <- lubridate::ymd(start_date)
  end_date   <- lubridate::ymd(end_date)

  # Interval length in months
  months_gap <-
    lubridate::time_length(
      lubridate::interval(start_date, end_date),
      unit = "months"
    )

  return(months_gap)
}
# One row per publication: its publication date, the date it was added to
# the Catalog, the gap between them (months), and the publication year
time_gap_summary <-
  gwas_study_info |>
  distinct(PUBMED_ID, DATE_ADDED_TO_CATALOG, DATE) |>
  mutate(catalog_gap = months_gap(DATE, DATE_ADDED_TO_CATALOG)) |>
  mutate(PUB_YEAR = lubridate::year(DATE))

Distribution of the gap for 2011–2020 publications

The analysis is now restricted to publications:

  • after 2010, once the GWAS Catalog was established, and
  • before 2021, so that recent publications that have not been curated yet do not bias the gap downwards.
time_gap_summary <-
  time_gap_summary |>
  filter(PUB_YEAR < 2021 & PUB_YEAR > 2010)
